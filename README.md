# Сколько стоит не лечить

Интерактивный расчет к докладу Ивана Джоя «Сколько стоит не лечить: экономика регенеративной терапии в клинике и на ферме» на III Международном конгрессе по регенеративной ветеринарной медицине ANIMALSTEM 2026 (СПбГУВМ, 15 октября 2026).

Открыть расчет: https://ivandzhoy.github.io/skolko-stoit-ne-lechit/

## Что считает

Страница с двумя режимами. Подставьте данные своей клиники или фермы: результат пересчитывается сразу.

- Клиника МДЖ: сколько процедур в месяц нужно, чтобы вход в метод окупился за выбранный срок, срок окупаемости при вашем плане, доход с пациента за год и бюджет, который владелец уже тратит.
- Ферма: стоимость одного случая болезни молочной коровы (лечение, недобор молока, замена коровы) и порог окупаемости курса в головах, килограммах молока и сутках браковки.

В расчете нет эффекта ни одного препарата. Значения по умолчанию помечены как «ориентир» (с источником) или «пример» (условное значение). Источники и допущения раскрываются на самой странице.

Прямые ссылки на режимы: `#clinic` и `#farm`.

## Как устроено

Один файл `index.html`: без сборки, без внешних скриптов, шрифтов и счетчиков. Введенные цифры остаются в браузере пользователя (localStorage) и никуда не отправляются.

Шрифты Manrope и Unbounded встроены в файл в урезанном виде (латиница и кириллица) по лицензии SIL Open Font License 1.1.

## Ограничения

Расчет иллюстративный. Он помогает спланировать пилот и не является прогнозом эффекта, рекомендацией по лечению или коммерческим предложением. Решения о лечении принимает ветеринарный врач.
